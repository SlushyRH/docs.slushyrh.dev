# Snowcap Doucmentation
Snowcap Documentation is my custom built documentation framework using React + Vite. I built this because I disliked the aggresive changes Gitbook has made recently, and what better than to make my own!

> [!NOTE]
> This is a template, not a package/framework! I built this for myself, so there are also most likely some bugs/issues here and there. If you find any, just raise an issue and I'll try my best to help.

# Features
- Isolated project documentation sites (one documentation site doesn't know about any others)
- Folder/file based slug system (uses the folder and file names as the slug)
- Multiple sub-folders with pages.
- Out-of-the-box component library.
- Custom styling through `main.css`.
